2. DELIVERABLE 2: Configured WAF Rule File

File Name: prestashop_custom_rules.conf | Location: /etc/modsecurity/prestashop_custom_rules.conf

# RULE 1000001: Cross-Site Scripting (XSS) Prevention
SecRule ARGS|REQUEST_COOKIES|REQUEST_HEADERS "@rx (?i)(<script[^>]*>.*?</script>|<script|javascript:|onload=|onerror=|alert\\(|<svg[^>]*onload)" \
    "id:1000001,phase:2,deny,status:403,log,msg:'[DEFENSE BLOCKED] Cross-Site Scripting (XSS) Attack Detected',severity:CRITICAL"

# RULE 1000002: SQL Injection (SQLi) Prevention
SecRule ARGS|REQUEST_URI "@rx (?i)(\\b(union(\\s+all)?\\s+select|select.*from|insert\\s+into|drop\\s+table)\\b|--\\s*|'\\s*or\\s*'1'='1|'\\s*or\\s*1=1)" \
    "id:1000002,phase:2,deny,status:403,log,msg:'[DEFENSE BLOCKED] SQL Injection (SQLi) Signature Detected',severity:CRITICAL"

# RULE 1000003: Directory Traversal and Sensitive File Access
SecRule REQUEST_URI|ARGS "@rx (?i)(\\.\\./\\.\\./|etc/passwd|config/settings\\.inc\\.php|\\.env|\\.git)" \
    "id:1000003,phase:1,deny,status:403,log,msg:'[DEFENSE BLOCKED] Directory Traversal or Sensitive File Access',severity:HIGH"

# RULE 1000004: Sensitive PrestaShop Installer Path Protection
SecRule REQUEST_URI "@rx ^/install/" \
    "id:1000004,phase:1,deny,status:403,log,msg:'[DEFENSE BLOCKED] Unauthorized Access to PrestaShop /install/ Path',severity:WARNING"

6. Architecture Note & Production Transition Strategy: Eliminating Port 8080

Why Two Ports Were Used During This Assessment

Exposing two ports was an intentional testing design to provide comparative proof:

  • Port 8080 (Vulnerable Baseline): Allowed testing of unshielded application code to prove vulnerabilities existed.
  • Port 80 (Protected WAF Gateway): Allowed validation that the Apache reverse proxy actively drops malicious payloads before forwarding clean traffic.

Production Hardening (How Port 8080 is Hidden in Real Life)

In a real-world enterprise deployment, Port 8080 is completely invisible to the outside world:

  1. Loopback Binding: The container is bound strictly to 127.0.0.1:8080 (localhost), preventing it from listening on external network interfaces. Nmap scans from the outside will show Port 8080 as closed/filtered.
  2. Firewall Enforcement: Host firewall rules drop any outside packets targeting 8080: 
    sudo ufw deny 8080
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
  3. Privileged Developer Access: Authorized developers and system administrators requiring direct container access connect securely via an encrypted SSH tunnel (ssh -L 8080:127.0.0.1:8080 user@10.0.0.5) or a corporate VPN, ensuring zero exposure to the public internet.
